<Warning>
  The current public alpha supports Linux and macOS. Windows packaging, automatic self-update, and user-level service installation are not yet shipped.
</Warning>

## 1. Install the binary

```bash
curl -fsSL https://install.bicameral-ai.com/install.sh | sh
bicameral --version
```

The installer downloads the matching release archive, verifies its SHA-256 checksum, and places the `bicameral` binary on your path.

<Note>
  Release binaries, `SHA256SUMS`, and `latest.json` are distributed through Bicameral's release-artifact path. When no compatible public alpha release exists, build from source rather than bypassing verification.
</Note>

## 2. Initialize a repository

```bash
cd /path/to/your-repository
bicameral init
bicameral doctor
```

`bicameral init` creates the workspace configuration needed by the local runtime. `bicameral doctor` checks local prerequisites and reports configuration problems before the service is started.

## 3. Start the local service

```bash
bicameral service start
```

The local service should remain bound to loopback unless a documented release explicitly supports another deployment. Do not expose the local gateway to an external network merely because the operating system permits it.

## 4. Open the hosted application

Open [app.bicameral-ai.com](https://app.bicameral-ai.com) and follow the supported pairing flow for the current release.

The hosted application does not automatically receive local credentials or local Decision Ledger authority. The exact information exchanged depends on the current release and configured integration.

## 5. Verify before using sensitive data

Before connecting a real repository or operational source:

- confirm the installed version and checksum;
- review the current release notes;
- confirm the local service binds only to the expected interface;
- connect only the sources you intend to use;
- verify where the selected event-store adapter keeps data; and
- retain normal source-control, backup, identity, and incident-response practices.

## Build from source

Developers can build the local runtime from the public repository:

```bash
git clone https://github.com/BicameralAI/bicameral-bot.git
cd bicameral-bot
cargo build --release --locked
cargo test --workspace
```

The source repository contains the authoritative developer quickstart, protocol documentation, tests, and architecture decisions for the local runtime.
